# ELS STEAM expedition batch — 9 November 2026

## Scope and counting

125 catalog expeditions: 25 each in Science, Technology, Engineering, Arts and Mathematics. TEC-001 extends and links the existing Signals in the Sky lesson; it is not counted a second time. The other 124 entries are new original ELS activities. Existing Learn articles remain separate from expedition counts.

This is website content and reusable JSON, not a native Android screen rollout. No additional third-party accounts, analytics, AI calls, uploads or child-data storage are introduced.

## Editorial status

All activities are authored starting versions for family use. They have not been field-tested with children, independently safety-certified or validated for learning outcomes. The brief duration estimates are planning aids. Each activity supplies a question, materials, three actionable steps, an evidence product, explanation, extension, specific safety note and optional reference. Activities remain usable without opening external references, except that Signals links its existing ELS companion lesson.

Background links are further-learning resources, not claims that a provider authored, endorsed or evaluated the ELS text. No third-party lesson text or imagery is copied. The existing branding is retained. Family feedback and measured usability should inform later revisions.

## Review and release

One pull request holds the full batch plus the previously requested three Science articles. Roger may review and merge the entire PR. The existing github-pages environment approval remains the final publication step. GitHub approval, merge and deployment are different actions; this change does not bypass the release gate.

## Editing

Edit the nine pipe-separated fields in content/<category>.txt: title, question, materials, three steps separated by " / ", evidence, explanation, extension, safety, reference key. Run `python3 scripts/build_expeditions.py`, then `python3 -m unittest discover -s tests -v`. IDs are assigned by row order; retain that order after publication so shared links remain stable. Refresh the release-readiness record after content changes.
